# Flicken für tgcalls

tgcalls wird nicht gegabelt, sondern geflickt: `tgcalls-bauen.sh` legt die
Flicken vor dem Übersetzen auf einen frischen Abzug. So bleibt sichtbar,
was von uns stammt und was von Telegram — und ein neuer Abzug bricht
sichtbar, statt still das Falsche zu tun.

| Flicken | wofür |
|---|---|
| `ohne-aec3.patch` | WebRTCs Echoausl&ouml;schung kostet auf dem OMAP3630 62,5 % eines Kerns und ist neben Nokias eigener doppelt gemoppelt |
